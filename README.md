# rdf-lsp

A language server for RDF, built on `tower-lsp`.

The notes are the exogram [Exogram rdf-lsp](exogram/01M3N4WG252RXXN2F0MD1YCC6N.md) in `exogram/`. This repository is a member of the Symbolith exogram workspace. The README of the root repository [symbolith-exogram](https://github.com/symbolith/symbolith-exogram) holds the setup.
